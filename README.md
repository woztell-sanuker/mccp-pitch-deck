# MCCP · Deck de inversión

Deck HTML autocontenido, bilingüe ES/EN (toggle en la esquina superior derecha o `?lang=en`).

- **Contenido:** copys canónicos v5.0 (fuente: cata de procedencia interna; slide 12 conserva v4.0). Slides 9 y 16 marcados «En revisión».
- **Identidad visual:** MCCP Design System (Claude Design).
- **Navegación:** flechas del teclado, clic para avanzar, `#n` enlaza al slide n.

## Confidencialidad

Material **confidencial-interno**, se comparte solo por enlace directo. Todo el HTML servido lleva `<meta name="robots" content="noindex, nofollow">`; este repositorio no sirve binarios. El repo es público únicamente porque GitHub Pages (plan Free) lo exige.
